## How to write an application that gets funded
Committees read hundreds of applications. The ones that get money share four traits:

1. **A specific thesis, not a category.** "AI agent that routes swaps across DEXs to cut slippage" beats "AI × DeFi platform".
2. **A reason it's on-chain.** If it works identically on AWS without a token, they'll notice.
3. **Evidence you can ship.** A repo, a prototype, a past project.
4. **A milestone the money completes.** "$40K gets the MVP to testnet in 8 weeks" is fundable. "$40K extends runway" is not.

Full template: [web3-grant-application-template](https://github.com/zkprimecapital/web3-grant-application-template). Longer read: [How to get a web3 grant in 2026](https://zkprime-capital.xyz/journal/grants.html?utm_source=github&utm_medium=awesome-web3-grants&utm_campaign=grants).
